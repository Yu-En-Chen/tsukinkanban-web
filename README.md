## 日本語

### このアプリが解決したいこと

首都圏の移動は、相互直通運転や乗り継ぎによって、一つの移動に複数の事業者・路線が関わります。一方で運行情報は事業者・路線ごとに発信されるため、「自分の移動に関わる路線はどれで、すべて問題ないか」を毎回自分で組み立て直す必要があります。

しかも生活の中には、通勤以外にも決まった移動があります。月に一度の帰省、子どもの通学、家族の通院、空港へのアクセス。こうした移動は通勤ほど意識が向かず、確認も後回しにされがちです。

知りたいのは「山手線が今どうか」ではなく、「今日、この移動がスムーズにできるか」のはずです。**通勤看板**は、運行情報の単位を「路線」から「いつもの移動（シーン）」に組み替えた Web アプリ（PWA）です。

### 仕組み

- 一枚のカード ＝ 一つの移動（例：「平日の通勤」「子どもの通学」「実家へ帰省」）
- 1 枚のカードに、事業者の異なる鉄道・バス路線を最大 6 つまで登録でき、鉄道とバスを混在できます
- フライトは情報量が多いため、1 便ごとの専用カード・専用レイアウトで表示します（鉄道・バスのカードと同じボードに並べられます）
- カード表面のランプが、移動全体の状態を〇△×で集約して表示します

カードを**開かなくても**、画面をひと目見るだけで「今日の自分の移動のうち、どれが順調でどれに注意が必要か」がわかります。ボードには最大 5 枚のカードを表示できます。

初期状態のカードと路線はデモ用のスターターデッキです。**カード名・路線・カラーはすべて自由に入れ替えられ**、自分の生活に合わせたボードを作れます。

### ランプの見方

| 記号 | 意味 |
|---|---|
| 〇 | 平常運転（鉄道は遅延 5 分以内） |
| △ | 遅れ（鉄道は 6〜15 分）、または遅延・見合わせ等の発表あり |
| × | 大幅な遅れ（鉄道は 16 分以上）、または情報取得エラー |
| 吹き出し | お知らせの発表、情報確認中など |
| 地震・雨風・雪 | 運行情報に該当する記述があるときのみ表示 |

記号の形、点灯／消灯の明るさ、ランプ横の文章でも状態を伝えるため、色だけに頼らずに読み取れます。

### 主な機能

| 機能 | 説明 |
|---|---|
| シーンカード | 鉄道・バス最大 6 路線を 1 枚のカードにまとめ、カードスタックで表示。タップで各路線の詳細を確認できます |
| カード表面のランプ | 〇△×の記号と文章で、移動全体の状態をカードを開かずに把握できます |
| 鉄道の遅延分数 | JR 東日本・都営地下鉄・横浜市営地下鉄は、列車ロケーション情報から方向別の遅延分数を表示。湘南新宿ライン・上野東京ラインは運転系統単位で、どの路線内の遅れかを示します |
| 方面名での表示 | 「上り／下り」ではなく「大宮・上野・東京方面」のように、行き先の分かる方面名で表示します |
| バス | 都営バス・横浜市営バス・西武バスに対応。停留所順の路線表示、走行中車両の位置、到着予測（あと○分／まもなく）、混雑度（提供がある場合）。カード上には自分で選んだ停留所（最大 2 つ）の到着予測を表示します |
| バス停留所検索 | 停留所名から、その停留所に停まる路線と到着情報を一覧できます |
| フライト | 羽田・成田の出発便・到着便に対応。JAL・ANA 便は搭乗口・ターミナル情報もあわせて表示します（Beta） |
| 空港へのナビゲーション | フライトカードから Google マップを起動し、空港・ターミナルへの経路案内を開始できます |
| 公式サイトへのショートカット | カードに登録した路線・バスの事業者公式サイトへ直接アクセスできます |
| 路線検索 | ヘッダーの検索から、鉄道・バス・フライトをインクリメンタルに検索・追加できます |
| パーソナライズ | カードの表示名やカラーを自由にカスタマイズ（端末内保存）。変更はワンタップで取り消せます |
| 同期時計 | 最終データ同期時刻を常時表示し、同期が途切れると警告します |
| 履歴 | 過去の運行状況を時系列で振り返ることができます |
| 設定のエクスポート／復元 | クリップボードを介して設定を書き出し・読み込みできます |

### プライバシー

- 会員登録不要・広告なし・サードパーティ Cookie なし
- カードの内容やパーソナライズ設定は端末内（ブラウザ）にのみ保存され、サーバーには一切送信されません
- 位置情報は取得しません
- 設定の引き継ぎはクリップボード経由で行い、サーバーを経由しません
- ホーム画面に追加すれば、ネイティブアプリのように利用できます（PWA 対応）

### データソース

本サービスは、公共交通オープンデータセンターにおいて提供されるデータを利用しています。データは、必ずしも正確・完全なものとは限りません。本サービスの表示内容について、公共交通事業者への直接の問合せは行わないでください。

- 一部のデータ（JR 東日本・東武鉄道・西武鉄道・京急電鉄・京王電鉄・東急電鉄の運行情報、成田・羽田のフライト情報など）は「公共交通オープンデータチャレンジ2026」限定で提供されているもので、2027 年 2 月末まで提供予定です
- 対応路線の一覧は、アプリ内「データ元」ページをご覧ください

> 本サービスは個人が開発・運営する**非公式**のサードパーティアプリであり、ODPT および各鉄道・交通事業者とは一切関係がありません。

### 技術構成

- **フレームワークなし** — HTML / CSS / JavaScript（ES Modules）のみで構築。動作にビルド工程は不要です
- **PWA** — `manifest.json` によるホーム画面追加・スタンドアロン表示に対応
- **状態保存** — IndexedDB（利用できない環境では localStorage）。サーバー側にユーザーデータは保存しません
- **通信の抑制** — バスのデータは、ボードにバス路線がある場合と検索時にのみ取得します
- **アイコン** — [Lucide Icons](https://lucide.dev/)（SVG インライン埋め込み）

### ローカルで動かす

ビルド不要です。任意の静的サーバーでルートディレクトリを配信してください。

```bash
# 例 1: Python
python3 -m http.server 8000

# 例 2: VS Code の Live Server 拡張機能で index.html を開く
```

ブラウザで `http://localhost:8000` を開けば動作します（運行データの取得には外部 API への接続が必要です）。

## 繁體中文

### 這個 App 想解決的問題

首都圈的移動因為直通運轉與轉乘，一趟移動常牽涉多家業者、多條路線。但運行資訊是依業者、依路線各自發布，使用者每次都得自己重新組合「我這趟會用到哪幾條、是不是全部沒問題」。

而且生活中除了通勤，還有其他固定的移動：每月回老家、小孩通學、家人就醫、前往機場。這些移動不像通勤那樣受到關注，確認也常被往後排。

你真正想知道的從來不是「山手線現在怎樣」，而是「我今天這趟，順不順」。**通勤看板**（つうきんかんばん）就是把運行資訊的單位，從「路線」重組成「日常固定的移動（場景）」的行動網頁應用程式（PWA）。

### 運作方式

- 一張卡片 ＝ 一趟移動（例如「平日通勤」「小孩通學」「回老家」）
- 一張卡片最多可登錄 6 條不同業者的鐵道、巴士路線，鐵道與巴士可混合
- 航班資訊量多，以一班一張的專用卡片與專屬排版呈現（可與鐵道、巴士卡片排在同一個看板上）
- 卡片正面的燈號以〇△×彙整整趟移動的狀態

**不用點開卡片**，掃一眼畫面就知道「今天我的哪趟移動順利、哪趟需要注意」。看板上最多顯示 5 張卡片。

初始畫面上的卡片與路線是展示用的起手牌組，**卡片名稱、路線、顏色全部都能自由替換**，組出符合自己生活的看板。

### 燈號說明

| 符號 | 意義 |
|---|---|
| 〇 | 正常運行（鐵道誤點 5 分以內） |
| △ | 延誤（鐵道 6～15 分），或有誤點、停駛等公告 |
| × | 嚴重延誤（鐵道 16 分以上），或資料取得錯誤 |
| 對話框 | 有公告、資訊確認中等 |
| 地震、雨風、雪 | 只在運行資訊有相關描述時顯示 |

以符號形狀、亮滅明暗、燈號旁的文字說明來傳達狀態，不只依賴顏色。

### 主要功能

| 功能 | 說明 |
|---|---|
| 場景卡片 | 最多 6 條鐵道、巴士路線收進一張卡片，以卡片堆疊呈現，點開可看各路線詳情 |
| 卡面燈號 | 以〇△×符號與文字，不點開卡片也能掌握整趟移動的狀態 |
| 鐵道誤點分鐘數 | JR 東日本、都營地下鐵、橫濱市營地下鐵由列車位置資料顯示各方向誤點分鐘數；湘南新宿線、上野東京線以運轉系統為單位，標示是在哪條路線內誤點 |
| 方向名稱 | 不用「上行／下行」，而用「大宮・上野・東京方面」這類看得出目的地的方向名 |
| 巴士 | 支援都營巴士、橫濱市營巴士、西武巴士。依站序顯示路線、行駛中車輛位置、到站預測（還有○分／即將進站）、擁擠度（有提供時）；卡片上顯示自選站牌（最多 2 個）的到站預測 |
| 巴士站牌搜尋 | 輸入站牌名稱，一覽停靠該站的路線與到站資訊 |
| 航班 | 支援羽田、成田的出發與抵達航班；JAL、ANA 航班一併顯示登機門、航廈資訊（Beta） |
| 機場導航 | 從航班卡開啟 Google 地圖，導航至機場或航廈 |
| 官網捷徑 | 直接開啟卡片內路線、巴士業者的官方網站 |
| 路線搜尋 | 從頂部搜尋列即時搜尋並加入鐵道、巴士、航班 |
| 個人化 | 自訂卡片的顯示名稱與顏色（僅存於裝置內），變更可一鍵復原 |
| 同步時鐘 | 常駐顯示最後資料同步時刻，同步中斷時發出警示 |
| 歷史紀錄 | 依時間軸回顧過去的運行狀況 |
| 設定匯出／還原 | 透過剪貼簿匯出、匯入設定 |

### 隱私

- 免註冊、無廣告、不使用第三方 Cookie
- 卡片內容與個人化設定只存在你的裝置（瀏覽器）內，不會上傳到伺服器
- 不取得位置資訊
- 設定的轉移透過剪貼簿完成，不經過伺服器
- 支援 PWA，加入主畫面後可像原生 App 一樣使用

### 資料來源

本服務使用公共交通開放資料中心提供的資料。資料不保證正確、完整。請勿就本服務的顯示內容直接詢問公共交通業者。

- 部分資料（JR 東日本、東武鐵道、西武鐵道、京急電鐵、京王電鐵、東急電鐵的運行資訊，以及成田、羽田的航班資訊等）為「公共交通オープンデータチャレンジ2026」限定提供，預定提供至 2027 年 2 月底
- 支援路線清單請見 App 內的「データ元」頁面

> 本服務為個人開發、營運的**非官方**第三方應用程式，與 ODPT 及各鐵路、交通業者皆無任何關係。

### 技術架構

- **無框架** — 純 HTML / CSS / JavaScript（ES Modules），執行不需要建置流程
- **PWA** — 透過 `manifest.json` 支援加入主畫面與獨立視窗顯示
- **狀態儲存** — IndexedDB（無法使用時改用 localStorage），伺服器端不儲存任何使用者資料
- **減少通訊** — 巴士資料只在看板上有巴士路線、或搜尋時才取得
- **圖示** — [Lucide Icons](https://lucide.dev/)（以行內 SVG 嵌入）
